# Mi primer proyecto con JavaScript

**Autora:** Mariangel Ortegate

## Descripción
Proyecto realizado para aprender JavaScript Vanilla, HTML, Git y GitHub.

## Temas aprendidos
- Variables y tipos de datos.
- Operadores matemáticos.
- Comparadores.
- Condicionales.
- Funciones.
- Manipulación del DOM.
- Eventos con addEventListener.

## Proyecto final
Se creó un contador dinámico que permite aumentar y disminuir un número mediante botones. También cambia de color dependiendo de su valor.

## Herramientas utilizadas
- Visual Studio Code
- HTML
- JavaScript
- Git
- GitHub
